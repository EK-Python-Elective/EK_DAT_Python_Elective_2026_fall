# Exercise: Your First Prompt to Vibe

**Type:** Individual — discuss in pairs

**Motivation:** Helps you understand how the tool uses its built-in capabilities to respond — and sets the baseline for how you'll interact with it throughout the semester.

---

Once the tool is running, send these three prompts in order and observe what happens:

1. `What does this project do?`
2. `Read the file vibe/core/agent_loop/_loop.py and summarise it in 3 bullet points`
3. `List all the files in the vibe/core/tools/ directory`

No code to write. Pay attention to which built-in tools vibe uses to respond (look for `read_file`, `bash` calls in the output). Compare your results with a classmate — did you get the same answers?
