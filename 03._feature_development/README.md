# Feature Development with AI Assistance

## Learning Goals
- Students can design and implement new features in a large project.
- They learn to use AI as a sparring partner but take ownership of the code.

## Before Class
- Brainstorm potential features or improvements for the mistral-vibe project.
- Review the project's issue tracker for inspiration.

## Today's Teachings
- **Feature Design:** Using AI to generate a plan for implementing a new feature.
- **Implementation:** Writing code with AI assistance and manually reviewing it for quality.
- **Testing and Documentation:** Generating tests and docstrings with AI.

## After Class
- Implement a small feature or improvement in the project.
- Write tests and documentation for the feature.
