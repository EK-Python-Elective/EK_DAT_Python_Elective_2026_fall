## Today's Teachings

### Demo format (10 min per group)

1. **Show it working** (3-4 min)
   - Live terminal demo — start `vibe`, trigger your feature, show the result
   - Show at least one edge case or error handling

2. **Explain the code** (3-4 min)
   - Open the most interesting file you wrote
   - Walk through 10-20 lines and explain what they do and why
   - Mention: what Python concepts did you use? (async, pathlib, type hints, etc.)

3. **Reflect** (2-3 min)
   - What was harder than expected?
   - What would you do differently?
   - How did AI tools help (or not help)?

### Reflection questions — discuss as a class

**On Python:**
- What Python features did you find most useful?
- What was confusing at first but makes sense now?
- How does Python compare to languages you have used before?

**On open source:**
- What surprised you about reading a real codebase?
- What makes a codebase easy or hard to contribute to?
- Would you contribute to open source again?

**On AI-assisted development:**
- When was AI most helpful? When was it misleading?
- Did using AI change *how* you think about code, or just *how fast* you wrote it?
- What skills do you need to use AI tools well?
