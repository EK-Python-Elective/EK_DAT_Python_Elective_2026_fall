# Introduction to the Project and Open Source

## Learning Goals
- Students can navigate a large Python project.
- They understand how to contribute to open source.
- They can use an AI CLI tool to explain and document code.

## Before Class
- Read the `README.md` and `CONTRIBUTING.md` files of the mistral-vibe project.
- Set up the project locally using the provided guide.

## Today's Teachings
- **Project Analysis:** Walkthrough of the mistral-vibe project structure, key components, and architecture.
- **Open Source Culture:** Understanding forks, pull requests, issues, and communication with maintainers.
- **AI-Assisted Onboarding:** Using AI to generate setup guides and explain code.

## After Class
- Navigate the mistral-vibe codebase and identify key components.
- Use AI to generate a summary of the project's architecture.
