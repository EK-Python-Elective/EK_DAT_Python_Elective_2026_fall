# Collaboration, Code Reviews, and PRs

## Learning Goals
- Students can collaborate on code and handle feedback.
- They understand how to contribute to open source.

## Before Class
- Review the project's pull request guidelines.
- Prepare a small feature or bug fix to contribute.

## Today's Teachings
- **Code Reviews:** Reviewing peers' code and providing constructive feedback.
- **Pull Requests:** Opening PRs, handling feedback, and iterating on work.
- **Documentation:** Using AI to generate or improve documentation.

## After Class
- Open a pull request for your feature or bug fix.
- Review and provide feedback on a peer's pull request.
