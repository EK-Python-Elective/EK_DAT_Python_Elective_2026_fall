# Code Quality and Infrastructure

## Learning Goals
- Students can assess and improve code quality.
- They understand how tests and infrastructure support a project.

## Before Class
- Review the project's existing tests and infrastructure files (e.g., `Dockerfile`, `.github/workflows`).
- Read about code quality tools like linters (flake8, black) and type hints.

## Today's Teachings
- **Code Quality:** Analyzing code for code smells, security risks, and performance issues using AI.
- **Testing:** Running and understanding the project's tests, generating new tests with AI.
- **Infrastructure:** Understanding deployment and CI/CD pipelines.

## After Class
- Use AI to analyze a specific file in the project for potential issues.
- Write a new test for a function in the project.
