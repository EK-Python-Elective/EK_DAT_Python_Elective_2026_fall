# EK_DAT Python Elective 2026 Fall

Course material for the Python Elective, fall 2026.

Each session has its own folder (`01._…`, `02._…`, …) with a README describing the session and its exercises.

## Exam

The exam is an **individual oral exam** based on a project you build yourself. The project is completely free: any Python application that uses elements from this semester. It must be a **finished, production-ready application**. You may build it alone or in a group, but hand-in and defence are **individual**.

- **Hand-in:** link to your GitHub repository, in Wiseflow, by **16 December at 12:00**
- **Oral exam:** 30 minutes: 10 min presentation, 15 min questions, 5 min deliberation and grade (7-point scale)

Details: [`09._eksamensprojekt/eksamensprojekt.md`](09._eksamensprojekt/eksamensprojekt.md). Advice and a checklist: [`09._eksamensprojekt/gode_raad_til_eksamens_projekt_og_eksamen.md`](09._eksamensprojekt/gode_raad_til_eksamens_projekt_og_eksamen.md).
